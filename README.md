## 🚀 Quick Start (For New Users)

Follow these steps to initialize the CodeOracle environment on your local machine:

### 1. Prerequisites
- **Node.js** (v18+)
- **XAMPP** (For MySQL Database)

### 2. Installation
```bash
# Clone the repository
git clone <your-repository-url>

# Enter the directory
cd code-oracle

# Install dependencies
npm install express mysql2 cors lucide-react framer-motion react-hot-toast react-markdown mermaid react-syntax-highlighter
```

### 3. Database Setup (XAMPP)
1. Open **XAMPP Control Panel** and start **Apache** and **MySQL**.
2. Open your browser and go to `http://localhost/phpmyadmin`.
3. Create a new database named `code_oracle_db`.
4. Click on your new database, go to the **Import** tab, and select the `database.sql` file from the project root.
5. Click **Go** to initialize the tables.

### 4. Running the Platform
You need to run **two terminals** simultaneously:

**Terminal 1: Start the SQL Bridge**
```bash
node server.js
```
*(Ensure the header shows `🟢 BRIDGE: ACTIVE` once the app is loaded)*

**Terminal 2: Start the Obsidian Interface**
```bash
npm run dev
```
